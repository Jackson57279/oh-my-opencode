### Added

- Devin CLI adapter (`packages/omo-devin`): the OMO agentic workflow as a declarative `.devin-plugin` plugin (`omo`) installable via `devin plugins install <repo>#packages/omo-devin/plugin` or `--local <path>`. Ships 19 generated `/omo:*` skills (shared bundle + canonical ultrawork directive with `## Codex*` compat sections rewritten for Devin), 7 `omo:*` subagent profiles (oracle, librarian, momus, metis, prometheus, multimodal-looker, sisyphus-junior) mirroring the omo tool restrictions, always-on + glob-triggered rules, a dependency-free `omo-hook.mjs` (SessionStart/UserPromptSubmit/PostCompaction with the ultrawork trigger and a `OMO_DEVIN_HOOK_LOG` JSONL event log), and remote MCP servers (grep_app, context7). Adds the `devin-qa` skill for sandboxed-XDG live CLI QA, `build:devin-plugin`/`test:devin` root scripts, and a `.devin/config.json` `requiredPlugins` entry (#1).
